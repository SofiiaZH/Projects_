# Global Sales Data Analysis

End-to-end sales data analysis using Python, Pandas, NumPy, Matplotlib and Seaborn.

The project focuses on cleaning, integrating and analysing global sales data to identify key business trends, profitability drivers, regional performance and delivery efficiency.

## Key Areas
- Data cleaning and preprocessing
- Missing values and anomaly detection
- Data integration
- Revenue, cost and profit analysis
- Product and regional performance
- Sales channel analysis
- Delivery time analysis
- Sales trends and seasonality
- Data visualisation

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn
