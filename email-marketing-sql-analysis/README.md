# Email Marketing SQL Analysis

Advanced SQL analysis of account and email activity data, focused on user metrics, email engagement and country-level performance.

The project combines data from multiple related tables to calculate account and email metrics, aggregate performance across different dimensions, and identify the top-performing countries.

## Key Areas

- Multi-table data integration using JOINs
- Common Table Expressions (CTEs)
- Account and email activity analysis
- Sent, opened and visited email metrics
- Data aggregation by date and country
- User verification and unsubscribe status analysis
- Window functions using ROW_NUMBER() and RANK()
- Country-level performance ranking
- Top 10 country analysis
- Data preparation for reporting and visualisation

## Tools

SQL, BigQuery
